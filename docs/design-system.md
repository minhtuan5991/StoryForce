# StoryForge US design system

An original desktop production workspace, with local system fonts and no remote assets.

The UI/UX skill search matched a general marketing landing-page pattern twice; that pattern was not applicable and was not used. The following product-specific decisions implement its relevant accessibility and dashboard guidance.

- Deep navy canvas, slate surfaces, pale blue primary action, amber production highlights.
- Segoe UI / system-ui typography, 15 px body, restrained 12 px metadata, 32 px page titles.
- Persistent workspace sidebar; breadcrumb path; project production steps grouped into story, quality, production.
- Clear empty states, visible action feedback, native forms, labels and focus outlines.
- Motion limited to short opacity transitions. Honor reduced-motion preferences.
- All status colors have text labels; all icon controls have accessible names.
- Responsive grids and a collapsible navigation rail below tablet width.
- Scores are explicitly heuristic; demo content and mock generation are labeled.
